# dev-mocks

個人開発のアイディア用に、**コンセプト画像とデザインモックだけ**を置く公開リポジトリ。
GitHub Pages で配信し、Notion の Ideas データベース（`Mock` 列・ページカバー）から参照する。

## 重要: すべてサンプルです

**このリポジトリの画像・モックに含まれる価格・数値・店名・企業名はすべて架空のサンプルです。**
実在の店舗の価格情報ではありません。デザイン検討のための表示例として作成しています。

## 構成

```
{アイディアのスラッグ}/
├── concept.png    コンセプト画像（Notionのページカバー用・16:9）
└── mock.html      デザインモック（任意）
```

URLは `https://toshimaru-dev.github.io/dev-mocks/{スラッグ}/concept.png` の形になる。

## 置くもの・置かないもの

| 置く | 置かない |
|---|---|
| コンセプト画像 | 競合調査の結論・分析 |
| デザインモック（HTML） | 未公開の着手計画・リリース時期 |
| 画面イメージ | 商標・法務まわりのメモ |
| | 収益の見込み・課金設計の検討 |

**判断材料や検討の経緯は Notion と private リポジトリに置く。** ここは成果物の置き場所に徹する。
